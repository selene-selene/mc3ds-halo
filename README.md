A very unfinished attempt at porting Minecraft for the Xbox 360's Halo mashup pack to the Nintendo 3DS edition, which consists of a Halo-themed texture pack, skin set, and a world. This port currently only has all block and item textures, and replaces the base game's vanilla textures until I figure the rest out. 


Major thanks to **SuperCatElvis** on Curseforge for originally porting over the mashup pack from Bedrock to Java, which is what this port relies on.

**Installation**

Create a folder with your game's ID as the name (which varies by region):

USA: 00040000001B8700, EUR: 000400000017CA00, JPN: 000400000017FD00.

Download and drop the provided romfs folder into that folder with the game ID, then move the resulting folder to the following location: (your microSD)/luma/titles. 
If you've downloaded mods for this game before, it's likely that the folder with the ID already exists.

Make sure you have game patching enabled in your Luma settings and you've removed any other mods likely to be incompatible.
